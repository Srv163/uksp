# УКСП — локальная сборка

Светлый сайт со сценой «цельная конструкция → раскрытие → новая сборка → реализация», блоком KRATNO INVEST и тремя согласованными проектами.

## Просмотр

Файл `index.html` уже собран. Для просмотра запустите из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/`. Установка npm-пакетов не требуется. Шрифты и Three.js находятся в `assets/`; внешние библиотеки с CDN не загружаются.

## Загрузка в репозиторий

Загрузите содержимое этой папки в корень репозитория: `index.html`, CSS и JS, папки `assets` и `data`, файл `build.mjs`. В ZIP эти файлы уже лежат в корне. Сборка не требует серверной части для просмотра.

## Проекты

Согласованный набор — три крупнейших реализованных проекта по цене продажи из файла «Портфолио 2023-2026.xlsx», лист «История»:

| Проект | Приобретение | Продажа без НДС | Срок владения |
| --- | ---: | ---: | ---: |
| Очистные в Раменском | 7 160 600 ₽ | 46 500 000 ₽ | 130 дней |
| Шлак никеля | 4 429 950 ₽ | 18 000 000 ₽ | 252 дня |
| Борисоглебск | 2 011 111,11 ₽ | 3 500 000 ₽ | 316 дней |

Данные хранятся в `data/projects.json`. Срок вычисляется от полной оплаты до продажи. Прибыль, доходность и оценки непроданных активов не публикуются. Исходный Excel не включён в сайт.

После изменения данных пересоберите раздел:

```sh
node build.mjs
```

## Основные файлы

- `index.html` — готовая страница.
- `architecture.css` — светлая тема, адаптация и карточки проектов.
- `styles.css`, `concept.css` — базовые стили остальных разделов.
- `scene-architecture.js` — 3D-сцена и управление прокруткой; предусмотрены выбор этапов, отключение плавного движения и статическое представление при недоступном WebGL.
- `app.js` — меню, KRATNO INVEST, формы и информационные окна.
- `build.mjs` — генерация карточек проектов из JSON, без зависимостей.

Форма работает в демонстрационном режиме и не отправляет контакты. Для приёма обращений нужен обработчик на том же домене, принимающий JSON и возвращающий `{"accepted":true}`. Его путь задаётся атрибутом `data-endpoint` формы. Юридические тексты формы сейчас описывают демонстрационный режим.

В `index.html` оставлен `noindex,nofollow` для предварительного просмотра. При выпуске публичной версии его можно убрать.

Лицензии сторонних компонентов: `assets/fonts/OFL.txt` и `assets/vendor/THREE-LICENSE.txt`.
