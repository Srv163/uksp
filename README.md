# УКСП — локальная сборка

Светлый сайт со сценой «цельная конструкция → раскрытие → новая сборка → реализация», блоком KRATNO INVEST и пятью реализованными проектами из портфолио 2023–2026.

## Просмотр

Файл `index.html` уже собран. Для просмотра запустите из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/`. Установка npm-пакетов не требуется. Шрифты и Three.js находятся в `assets/`; внешние библиотеки с CDN не загружаются.

## Загрузка в репозиторий

Загрузите содержимое этой папки в корень репозитория: `index.html`, CSS и JS, папки `assets` и `data`, файл `build.mjs`. В ZIP эти файлы уже лежат в корне. Сборка не требует серверной части для просмотра.

## Проекты

Согласованный набор — все пять реализованных проектов, по убыванию цены продажи, из файла «Портфолио 2023-2026.xlsx», лист «История»:

| Проект | Приобретение | Продажа без НДС | Срок владения |
| --- | ---: | ---: | ---: |
| Очистные в Раменском | 22 000 000 ₽ | 46 500 000 ₽ | 130 дней |
| Шлак никеля | 8 000 000 ₽ | 18 000 000 ₽ | 252 дня |
| Борисоглебск | 2 011 111,11 ₽ | 3 500 000 ₽ | 316 дней |
| Два здания в Кольчугино | 1 312 000 ₽ | 2 000 000 ₽ | 60 дней |
| Здание в Моршанске | 411 300 ₽ | 700 000 ₽ | 522 дня |

Данные хранятся в `data/projects.json`. Срок вычисляется от полной оплаты до продажи. Маржа (выручка − вход, до налогов и расходов) публикуется только суммарно по двум группам на `kratno.html`; оценки непроданных — только общей суммой («плановая выручка», «плановая маржа»), с оговоркой, что это не прогноз и не обещание результата. Чистая прибыль и доходность в процентах не публикуются. Исходный Excel не включён в сайт.

После изменения данных пересоберите раздел:

```sh
node build.mjs
```

## Основные файлы

- `index.html` — готовая страница.
- `architecture.css` — светлая тема, адаптация и карточки проектов.
- `styles.css`, `concept.css` — базовые стили остальных разделов.
- `scene-architecture.js` — 3D-сцена и управление прокруткой; предусмотрены выбор этапов, отключение плавного движения и статическое представление при недоступном WebGL.
- `app.js` — меню, KRATNO INVEST, формы и информационные окна.
- `build.mjs` — генерация карточек проектов из JSON, без зависимостей.
- `kratno.html` — страница платформы KRATNO INVEST (`/uksp/kratno.html`). `build.mjs` её не собирает; сумм отдельных проектов на ней нет — только итоги портфолио в разделе «08 / Опыт» (два блока: завершённые проекты — вход 33,7, выручка 70,7, маржа 37,0 млн ₽; проекты в работе — вход 43,5, плановая выручка 108,5, плановая маржа 65,0 млн ₽; всего 10 проектов, вложено 77,2 млн ₽) и ссылка на `index.html#cases`. Итоги вписаны вручную: при правке `data/projects.json` или портфолио сверить. Форма демонстрационная и ничего не отправляет.
- `kratno.css` — стили только для `kratno.html`, подключаются после `architecture.css`.
- `kratno.js` — скрипт `kratno.html`. Содержит копии фрагментов `app.js` (шаги платформы, меню, окна «Персональные данные» и «Согласие», cookie, раскрытие перед печатью) — при их правке в `app.js` синхронизировать.

Форма работает в демонстрационном режиме и не отправляет контакты. Для приёма обращений нужен обработчик на том же домене, принимающий JSON и возвращающий `{"accepted":true}`. Его путь задаётся атрибутом `data-endpoint` формы. Юридические тексты формы сейчас описывают демонстрационный режим.

В `index.html` оставлен `noindex,nofollow` для предварительного просмотра. При выпуске публичной версии его можно убрать.

Лицензии сторонних компонентов: `assets/fonts/OFL.txt` и `assets/vendor/THREE-LICENSE.txt`.
